# Landing Page for NeuroNexus Innovations
 
Create a Google Form-like web form using only HTML and CSS (no JavaScript).
The form must collect the following details:
1. Full Name (Text Input)
2. Contact Number (Phone Input)
3. Address (Multiline Textarea)
4. Company Name (Text Input)
5. Email Address (Email Input)
6. Department (Dropdown/Select Menu with options like HR, Sales, Development, Marketing, Others)
7. Gender (Radio Buttons: Male, Female, Prefer not to say)
8. Submit Button
